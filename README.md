# dsh-worldbook

本插件把 SillyTavern 的世界书搬到 DSH 里，并在此基础上补了两个很实用的能力：**让 AI 自己写世界书**、**编写的权限设置**。

---

## 这个项目能干嘛

- **用世界书**：新建、导入、编辑、导出世界书，给 AI 挂一套背景设定。
- **兼容 SillyTavern**：SillyTavern 的世界书 JSON 可以直接导入用，语义和注入行为也对齐。
- **让 AI 自己维护设定**：开启「开发世界书模式」后，AI 能自己新建世界书、增删改条目，适合做角色扮演/创作类工作区。
- **智能注入**：不是把所有设定一次性塞给 AI，而是按关键词等规则**挑相关的注入**，省上下文、更精准。

## 主要特点

| 特点 | 说明 |
| --- | --- |
| 🗂️ 兼容 SillyTavern 世界书 | 导入/导出 ST JSON，字段与注入语义全对齐（详见下文） |
| 🤖 世界书开发模式 | 让 AI 自己编写世界书，可配置增/删/改/查权限 |
| 🎯 注入系统 | 关键词触发 + 递归 + 粘性/冷却/延迟 + 概率 + 组互斥等 |
| 🎨 界面主题 | 可跟随 DSH 主题，也可用独立的粉色主题 |
| 🧩 可集成 | 世界书管理页和设置卡片都能嵌进你自己的插件里 |

## 快速上手

1. **安装**：克隆仓库后执行 `npm install && npm run build`，把插件放进 DSH 的插件目录。
2. **启用**：在 DSH 设置 → 插件里启用本插件。
3. **建书**：打开「世界书」页面，新建一本，或直接导入 SillyTavern 世界书 JSON。
4. **编辑条目**：选中世界书，新增条目，填关键词和内容。
5. **验证注入**：在会话里提到关键词，观察该条目的设定是否出现在模型上下文里。

> 设置页里有「启用开关」「生效工作区」「主题」「注入时机」「开发世界书模式」等选项，按需调整即可。

## 与 SillyTavern 世界书的兼容

这是本插件的核心卖点：不只读得了 SillyTavern 的格式，注入行为也尽量对齐，尽量做到「搬家即用」。

### 数据格式兼容

| 能力 | 说明 |
| --- | --- |
| 导入 | 直接导入 SillyTavern 世界书 JSON（`.json`） |
| 导出 | 导出为 SillyTavern 可用的 JSON |
| 字段映射 | 条目的所有核心字段一一对应，高级字段也保留还原 |

### 条目字段兼容

| ST 字段 | 含义 | 支持 |
| --- | --- | --- |
| `keys` / `keysecondary` | 触发关键词 / 副关键词 | ✅ |
| `comment` | 条目标题 / 备注 | ✅ |
| `content` | 注入到模型的内容 | ✅ |
| `constant` | 常驻（无条件始终注入） | ✅ |
| `selective` / `selectiveLogic` | 选择性（结合副关键词） | ✅ |
| `order` / `insertionOrder` | 注入优先级 | ✅ |
| `position` | 注入位置（0–7，对齐 ST 枚举） | ✅ |
| `depth` | @D 深度（聊天指定位置插入） | ✅ |
| `enabled` | 启用 / 停用 | ✅ |
| `caseSensitive` / `matchWholeWords` | 大小写 / 整词匹配 | ✅ |
| `scanDepth` | 扫描最近 N 条消息 | ✅ |
| `sticky` / `cooldown` / `delay` | 粘性 / 冷却 / 延迟 | ✅ |
| `probability` / `useProbability` | 命中概率 | ✅ |
| `excludeRecursion` / `preventRecursion` / `delayUntilRecursion` | 递归控制 | ✅ |
| `priority` / `vectorized` / `group` / `role` / `triggers` 等 | 高级字段 | ✅ 保留还原 |

### 注入行为兼容

| 行为 | 说明 |
| --- | --- |
| 关键词触发 | 对话命中关键词，注入对应条目 |
| 常驻注入 | `constant` 条目无条件始终注入 |
| 递归扫描 | 已注入内容里的关键词，可继续触发其它条目 |
| 粘性 sticky | 命中后若干条消息内强制注入 |
| 冷却 cooldown | 命中后若干条消息内不再注入 |
| 延迟 delay | 会话刚开始的若干条消息内强制注入 |
| 选择性 | 按副关键词的组合逻辑过滤 |
| 概率 | 按百分比决定本次是否注入 |
| 组互斥 | 同一分组内按优先级取一条 |
| @D 深度插入 | 把条目插到聊天中指定深度位置（可指定角色） |
| 位置 / 排序 | 对齐 ST 的 position 与 order |

> 注入相关的时间游标对齐 ST 的 `chat.length`（只按真实对话消息推进），保证跨轮行为（粘性/冷却/延迟）与 SillyTavern 一致。

## 二次开发 / 集成

如果你不满足于直接用，可以：

- **给插件加功能 / 改注入逻辑 / 扩展数据模型**；
- **把世界书 UI 集成进你自己的插件**：世界书管理页 + 插件设置卡片，通过 DSH 槽位对接；
- **只用它的能力**：直接调用注入引擎，或走 REST API 读写世界书。

详细说明见 **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**（数据层、注入引擎、REST API、槽位契约）。

## 配置项一览

在插件的「设置」里可以配置：

| 配置 | 说明 |
| --- | --- |
| 启用开关 | 关闭后世界书不再注入 |
| 生效工作区 | 全部工作区 / 仅指定工作区 |
| 主题 | 跟随 DSH 主题 / 独立粉色主题 |
| 注入时机 | 正文注入（默认）/ 每轮注入（不推荐，可能重复） |
| 开发世界书模式 | 开启后向 AI 暴露世界书编辑工具 |
| AI 权限 | 控制 AI 能增 / 删 / 改 / 查哪些操作 |

---

## 已知限制

- 世界书编辑目前是**书级**的（以一本世界书为单位进行管理），还没有**条目级**的独立编辑能力。
- 开发世界书模式下，AI 的编辑范围受「开发模式」与「AI 权限」约束，属安全设计。
